# Аналитический API

Этап 14 — самостоятельное FastAPI-приложение для чтения результатов этапов 0–13.
Оно запускается отдельно от интерфейса парсера и не содержит его startup-обработчиков.

1. Примените миграции до `d0e1f2a3b4c5` и загрузите snapshot отзывов и запуск разметки.
2. Укажите `POSTGRES_*` в `.env`. Для эксплуатации используйте пользователя БД с правами SELECT.
3. Сгенерируйте два разных случайных секрета, например командой
   `.venv/bin/python -c 'import secrets; print(secrets.token_urlsafe(32))'` для каждого.
4. Запишите их в `ANALYTICS_API_TOKEN` и `ANALYTICS_PRIVATE_TOKEN`.
5. Запустите сервер:

```bash
.venv/bin/uvicorn src.web.analytics_app:app --host 127.0.0.1 --port 8001
```

Документация OpenAPI доступна на `http://127.0.0.1:8001/docs`. Во вкладке Authorize вводится нужный Bearer-токен.
Для доступа через сеть используйте HTTPS. Публичный деплой и настройка reverse proxy относятся к этапу демонстрации.

| GET-метод | Обязательные параметры | Результат |
|---|---|---|
| `/api/analytics/summary` | `dataset_id` | Сводка snapshot |
| `/api/analytics/organizations` | `dataset_id` | Клиники, рейтинги, объём данных |
| `/api/analytics/problems` | `run_id` | Жалобы, mixed, сильные стороны, проверка разметки |
| `/api/analytics/monthly` | `dataset_id` | Месячные рейтинги и объёмы |
| `/api/analytics/problem-monthly` | `run_id` | Месячные показатели категорий |
| `/api/analytics/priorities` | `run_id` | Ранжирование и рекомендации этапа 13 |
| `/api/analytics/private/examples` | `run_id`, `category_id` | Тексты примеров со статусом accepted |

Агрегатные методы требуют `ANALYTICS_API_TOKEN`. Приватные примеры требуют только отдельный
`ANALYTICS_PRIVATE_TOKEN`: агрегатный токен не открывает исходный текст. Совпадающие токены блокируют
приватный метод. При пустых настройках доступ закрыт (503); при неверном токене возвращается 401.
Проверенные примеры по-прежнему содержат исходные персональные сведения: их можно показывать только
авторизованным аналитикам, а не в публичном DataLens.

`run_id` — числовой ID из `analytics.problem_runs`, `dataset_id` — ID из `analytics.datasets`.
Списки имеют `limit` от 1 до 200 и `offset >= 0`; предел по умолчанию — 50, для примеров — 5.
Методы категорий, динамики и примеров поддерживают `organization_id`. Сортировка стабильна.
Неизвестный dataset/run даёт 404; отсутствие строк при фильтрации — пустой список.
Пропущенные месяцы остаются отсутствующими; график не должен интерпретировать их как нулевую активность.

Каждый запрос выполняется в транзакции PostgreSQL `READ ONLY`. Ошибка SQL возвращает 503 без SQL,
параметров и текста отзывов. Агрегатные ответы имеют явные схемы и не содержат текстов или ID доказательств;
в рекомендациях сохраняется статус `review_required` и объяснение балла. Сервис не запускает ML и не меняет разметку.
