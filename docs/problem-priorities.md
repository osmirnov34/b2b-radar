# Приоритеты проблем и рекомендации

Этап 13 читает один явно выбранный запуск разметки из PostgreSQL. Перед запуском примените миграции до
`d0e1f2a3b4c5`: она исправляет KPI этапа 12, исключая `rejected` из количества сигналов, долей и средней
уверенности. В витрине качества счётчик отклонений сохраняется. `accepted_complaint_count/share` и
`unreviewed_complaint_count/share` позволяют различать подтверждённые и предварительные жалобы.

```bash
.venv/bin/python scripts/rank_analytics_problems.py 1
```

Аргумент — ID из `analytics.problem_runs`, а не строковый RUN_ID ML-пайплайна. Команда выводит JSON для
дальнейшего API, дашборда и отчёта. Операция читает БД и не изменяет разметку.

Баллы приоритета от 0 до 100 складываются из следующих компонентов:

- до 60 баллов: доля жалоб среди всех отзывов организации;
- до 15: объём жалоб, `log(1 + count) / log(101)`, с ограничением сверху;
- до 15: средняя оценка уверенности среди неотклонённых оценок категории;
- до 10: рост доли жалоб на 10 процентных пунктов между двумя завершёнными календарными месяцами.

Месяцы отсчитываются от времени формирования запуска (UTC), поэтому повторное чтение даёт тот же период.
Динамика учитывается только при наличии не менее 30 отзывов в каждом месяце; отсутствие периода не считается
нулевой долей жалоб. При отсутствии динамики компонент равен нулю, остальные веса не перераспределяются.
Сортировка стабильна: балл по убыванию, затем ID организации и категории.

Категории без жалоб не ранжируются; mixed и praise остаются отдельными показателями витрин. Если есть
непроверенные жалобы или всего менее 30 отзывов, результат получает `review_required` и первым действием
предлагает проверку разметки. Иначе статус — `investigate`. Рекомендации — русскоязычные шаблоны проверок
по категориям, а не автоматически установленные причины проблем. Балл отражает очередь исследования;
финансовую окупаемость и потери дохода он не измеряет. Числа уверенности базовой разметки — эвристические.

В результате возвращаются до трёх ID подтверждающих жалоб на категорию, с приоритетом принятых оценок.
Отклонённые оценки и тексты отзывов в этот вывод не попадают. ID служат ссылками на закрытый корпус.

При откате миграции восстанавливаются прежние формулы витрин; их новые столбцы удаляются.
